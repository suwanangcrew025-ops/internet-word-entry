The Internet in One Word: one word for the whole internet, funniest and most fitting wins. This entry's word is **doomscroll** — the verb for what everyone actually does on the internet now: open one app to check one thing, look up an hour later with a sore thumb and a worse mood, still scrolling.

## Run it

```sh
python3 main.py
```

It writes the single word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
